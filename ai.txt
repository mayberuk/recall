# What this project is, for an agent that got here first.
Summary: recall searches every past coding-agent session transcript on a machine — Claude Code
  and Codex CLI — from any checkout of a repo, without an index. It speaks the Model Context
  Protocol, so an agent can ask it directly rather than shelling out.
